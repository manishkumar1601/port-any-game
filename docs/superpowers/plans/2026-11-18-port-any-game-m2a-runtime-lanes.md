# M2a Upstream-Runtime Lanes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make `rt-easyrpg`, `rebuild-love` and `rebuild-renpy` real lanes (pinned runtime, build, adapter, verify) that pass the lane e2e on Windows, macOS and Ubuntu.

**Architecture:** each lane follows the M1 lane contract (`docs/lanes.md`).
- `rt-easyrpg` and `rebuild-love` are BYO runtime lanes like `rt-ruffle`. The adapter feeds the user's files from OPFS to an upstream wasm runtime.
- `rebuild-renpy` is a bundled rebuild lane. The build step runs the pinned Ren'Py SDK headless, and the output is served through web-extract's iframe adapter.
- Shared work comes first: setup extras and zip strip, pack guard rails, a WebGL frame-hook fallback, and a reusable web-build helper.

**Tech Stack:** Node ≥ 20.12 (dev and CI on 22), zero runtime dependencies, ESM `.mjs`, `node:test` (serial), headless Chrome/Edge over CDP for e2e, GitHub Actions on three operating systems.

**Spec:** [docs/superpowers/specs/2026-11-18-m2a-runtime-lanes-design.md](../specs/2026-11-18-m2a-runtime-lanes-design.md). Evidence: [f-easyrpg-web](../../spikes/f-easyrpg-web.md), [g-lovejs](../../spikes/g-lovejs.md), [h-renpy-web](../../spikes/h-renpy-web.md). Read the spec and the spike for your lane before starting.

## Global Constraints

- Node ≥ 20.12, zero runtime dependencies, ESM `.mjs`, `node:path` for every path. Compare real paths where links can be involved.
- No unnecessary comments; a needed comment is one short line. Match the surrounding style (see `memory/conventions.md`).
- TDD: every behaviour change has a test that fails first. Fixtures are our own MIT content, generated by `test/fixtures/make-*.mjs`; never game data, never third-party game assets.
- No GPL code in the repo. Runtimes are downloaded by `pag setup` into the user cache and never vendored.
- Lane contract per `docs/lanes.md`. `detect` stays pure (it reads the survey only). Build facts go in `build/lane.json` and reach the browser as `lane_config` through `shell()`.
- A lane may only add quoted CSP keywords (`cspFor` in `pack.mjs`).
- Exit codes: 0 ok, 1 fail, 2 usage, 4 policy refusal.
- Commit as the repo-local git identity, conventional message, no AI attribution or co-author trailers. Push `master` after each task. Never force-push.
- Before each commit: `PAG_E2E=0 npm test` is green (serial, about 6 min; a single timing flake under load may be rerun once). `npm run validate` and `node scripts/gen-wrappers.mjs --check` are OK. The task's own e2e passes locally (`node test/e2e/run.mjs <lane>`).
- Each task updates the docs it affects in the same commit: `docs/lanes.md`, the lane runbook in `skills/port-any-game/references/lanes/`, the `SKILL.md` lane table, `docs/cli.md`.

## Review Focus

1. **RPG Maker files in another case than the database asks for** (`TITLE/TITLE.PNG` requested as `Title/Title.png`): it must load. The gencache index maps lower-case keys to real names. Pinned by a Task 4 unit test.
2. **RPG Maker game one folder down** (`install/Game/RPG_RT.ldb`): the build finds the root, and the adapter serves paths under it. Pinned by a Task 4 unit test.
3. **Fused LÖVE exe whose zip offsets are absolute** (Info-ZIP `-A` style, not `copy /b`): the build must not produce an invalid slice. It falls back to `offset: 0`, the whole file, which LÖVE's PhysFS opens. Pinned by a Task 5 unit test.
4. **Port path with spaces or non-ASCII** for the Ren'Py SDK spawn: the build runs, because arguments go as an array with no shell. Pinned by a Task 6 unit test using a fake SDK.
5. **Ren'Py SDK build fails** (non-zero exit or "Web support is not available"): `pag build` exits non-zero with the SDK's last lines, and no half-built `build/game` remains. Pinned by a Task 6 unit test using a fake SDK.
