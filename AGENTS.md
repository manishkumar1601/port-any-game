# port-any-game: agent instructions

Before starting work, read:

1. `memory/README.md`: how project memory works, plus the session history.
2. `memory/project.md`: goal, constraints and current status.
3. `memory/conventions.md`: git, code, test and docs rules (work on `master`; no AI co-author trailers; no unnecessary comments).

When you need to know how part of the system works, start from `docs/README.md`.

Before finishing, add a session log as `memory/sessions/dd-mm-yyyy-topic-name.md` and add a row for it in `memory/README.md`.
